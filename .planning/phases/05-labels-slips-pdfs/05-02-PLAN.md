|----------|-------------|
| MCP client → Next.js MCP route | Untrusted inbound. Clerk gate is the only credential check. |
| MCP handler → graph.quiqup.com/return_order_label/{orderId} | Egress over TLS with Bearer JWT via the Clerk → Quiqup bridge. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-10 | Tampering | order_id path injection | mitigate | `encodeURIComponent(args.order_id)` applied at the URL-interpolation boundary. Acceptance criteria grep-locks the call. Tests assert `/` (and other path chars) is percent-encoded in the outbound URL. |
| T-05-11 | Information Disclosure | Return-label PDF body contains customer details | accept | Same disposition as Wave-1's T-05-05 — the PDF is the same artifact a Quiqdash operator gets from the UI button. PII risk equals the existing UI flow. |
| T-05-12 | Tampering | filenameHint reflection of caller-supplied order_id | mitigate | The filenameHint uses the RAW caller-supplied `order_id` (not the encoded form), but the surface is the `resource.uri` + the JSON metadata text block — neither is interpreted as a path by the LLM transport. The URL surface (which IS path-interpreted) uses the encoded form. Tests assert this split. |
| T-05-13 | Denial of Service | Repeated large PDF downloads | accept | Read-only tool, no rate limit (matches `download_pending_labels` / `download_orders_export` precedent). Per-call cost is bounded by a single upstream PDF response. |
| T-05-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed. Uses existing zod + msw + stdlib `fetch` + `Buffer`. |
